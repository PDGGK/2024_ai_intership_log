# 图像对比功能开发：从传统方法到大模型

> **日期**: 2024-12-14
> **主题**: Qwen-VL 视觉大模型应用与 JSON 解析处理

---

## 今天的任务

开发一个通用的图片对比分析功能，用于比较两张图片的相似度和差异。

---

## 技术方案选择

### 传统计算机视觉方法

一开始考虑用传统方法：
- SIFT 特征点匹配
- 像素级对比
- OpenCV 工具链

优点是速度快、结果确定，但只能做底层特征对比，无法理解图像的语义内容。

### 视觉大模型方法

最终选择用 Qwen-VL 视觉大模型：
- 能理解图像语义
- 可以用自然语言描述差异
- 输出更符合业务需求

## 遇到的问题：JSON 解析

大模型返回的 JSON 经常格式不规范：
- 多余的 markdown 标记
- 特殊字符
- 格式错误

### 解决方案

```python
def sanitize_json_string(text: str) -> str:
    """清理和规范化 JSON 字符串"""
    # 1. 去除 markdown 代码块标记
    text = re.sub(r'```json\s*', '', text)
    text = re.sub(r'```\s*', '', text)

    # 2. 提取 JSON 部分
    pattern = r'[\{\[].*[\}\]]'
    match = re.search(pattern, text, re.DOTALL)
    if not match:
        raise ValueError("No JSON found")

    # 3. 清理特殊字符
    json_str = match.group()
    json_str = json_str.replace('\n', ' ')
    json_str = re.sub(r'\s+', ' ', json_str)

    return json_str
```

## 今日反思

今天最大的收获是体验了视觉大模型的能力。

传统 CV 方法和大模型方法各有优劣。传统方法适合精确的像素级对比（比如找 bug、做 diff），大模型适合语义级理解（比如"这两张广告的设计风格是否一致"）。选择哪种要看具体需求。

另一个教训是：**大模型的输出需要容错处理**。模型返回的 JSON 经常不规范，不能直接 `json.loads()`，要先清理。这个问题在所有 LLM 应用中都会遇到。

# 图像对比系统的自适应内存管理

> **日期**: 2024-11-28
> **主题**: 显存动态监控与图像质量自适应控制

---

## 问题回顾

之前的图像对比系统有个严重问题：处理大图时显存溢出（尝试分配 254GB 显存）。虽然之前做了一些优化（串行处理、尺寸限制），但还是不够智能——参数是写死的，不能根据实际显存情况调整。

今天的目标是实现一个自适应的内存管理系统。

---

## 核心思路

设计三个组件：
1. **显存监控器**：实时监控显存使用情况
2. **质量控制器**：根据显存状态调整图像处理参数
3. **自适应处理器**：整合上述组件，实现自适应处理流程

---

## 显存监控器

```python
class MemoryMonitor:
    """实时监控显存使用情况"""

    def __init__(self):
        self.warning_threshold = 0.8   # 80%开始警告
        self.critical_threshold = 0.9  # 90%临界状态

    def check_memory_status(self) -> Tuple[float, str]:
        """返回显存使用率和状态"""
        try:
            gpu_memory = torch.cuda.memory_allocated()
            total_memory = torch.cuda.get_device_properties(0).total_memory
            memory_ratio = gpu_memory / total_memory

            if memory_ratio > self.critical_threshold:
                return memory_ratio, "临界"
            elif memory_ratio > self.warning_threshold:
                return memory_ratio, "警告"
            return memory_ratio, "正常"

        except Exception as e:
            logger.error(f"显存监控失败: {str(e)}")
            return 0.0, "未知"
```

## 质量控制器

定义三个质量等级，根据显存状态动态切换：

```python
class ImageQualityController:
    """根据显存状态动态调整图像处理参数"""

    def __init__(self):
        self.quality_levels = {
            "高": {"size": (1024, 1024), "quality": 95},
            "中": {"size": (800, 800), "quality": 85},
            "低": {"size": (512, 512), "quality": 75}
        }

    async def adjust_quality(
        self,
        memory_status: float,
        current_image: Image.Image
    ) -> Tuple[Image.Image, Dict[str, Any]]:
        """根据显存使用率选择合适的质量等级"""

        # 显存使用率决定质量等级
        if memory_status > 0.9:
            target_level = "低"
        elif memory_status > 0.8:
            target_level = "中"
        else:
            target_level = "高"

        params = self.quality_levels[target_level]

        # 调整图像
        processed_image = await self._process_image(
            current_image,
            params["size"],
            params["quality"]
        )

        return processed_image, params
```

## 自适应处理器

把监控器和控制器整合起来：

```python
class AdaptiveProcessor:
    """自适应图像处理器"""

    def __init__(self):
        self.memory_monitor = MemoryMonitor()
        self.quality_controller = ImageQualityController()

    async def process_image(self, image_file: UploadFile) -> Tuple[Image.Image, Dict]:
        """
        处理流程：
        1. 检查显存状态
        2. 读取原始图像
        3. 根据显存状态调整质量
        4. 返回处理结果
        """
        # 检查显存
        memory_ratio, status = self.memory_monitor.check_memory_status()

        # 读取图像
        content = await image_file.read()
        original_image = Image.open(BytesIO(content))

        # 自适应调整
        processed_image, params = await self.quality_controller.adjust_quality(
            memory_ratio,
            original_image
        )

        logger.info(
            f"图像处理完成: 显存使用率={memory_ratio:.2%}, "
            f"状态={status}, 质量等级={params}"
        )

        return processed_image, params
```

## 今日反思

今天实现的自适应系统比之前的固定参数方案好很多。

之前的问题是"一刀切"——所有图片用同样的参数处理。显存够的时候浪费了图像质量，显存不够的时候直接 OOM。现在能根据实际情况动态调整，既保证了稳定性，也尽可能保留了图像质量。

这个思路其实在很多场景都适用：**不是简单地设置一个"安全"的参数，而是根据实时状态动态调整**。比如网络请求的超时时间、批处理的 batch size 等，都可以做成自适应的。

另外一个收获是：**把复杂逻辑拆分成小模块**。显存监控、质量控制、处理流程分开，每个模块职责单一，测试和维护都更方便。

## Async Context Manager for Files

```python
class AsyncFileManager:
    def __init__(self, file: UploadFile):
        self.file = file
        self.content = None
        self.copies = []

    async def __aenter__(self):
        self.content = await self.file.read()
        return self

    async def __aexit__(self, exc_type, exc_val, exc_tb):
        for copy in self.copies:
            copy.close()
        if self.file:
            await self.file.close()

    def create_copy(self) -> BytesIO:
        copy = BytesIO(self.content)
        self.copies.append(copy)
        return copy
```

Usage:
```python
async with AsyncFileManager(file) as manager:
    copy1 = manager.create_copy()
    copy2 = manager.create_copy()
    # Use copies, they'll be cleaned up automatically
```

## Chunked Reading for Large Files

```python
async def read_large_file(file: UploadFile, chunk_size: int = 8192):
    buffer = BytesIO()
    while True:
        chunk = await file.read(chunk_size)
        if not chunk:
            break
        buffer.write(chunk)
    buffer.seek(0)
    return buffer
```

This avoids loading entire files into memory at once.

## Layered Validation Architecture

```plaintext
Input Layer         → File existence, type, size
Processing Layer    → Business rules, data transformation
Output Layer        → Result formatting, error handling
```

Each layer is independent and testable:

```python
class FileValidationService:
    @staticmethod
    async def validate_file_type(file: UploadFile, allowed: List[str]) -> bool:
        return file.content_type in allowed

    @staticmethod
    async def validate_file_size(file: UploadFile, max_bytes: int) -> bool:
        content = await file.read()
        file.file.seek(0)
        return len(content) <= max_bytes
```

## Today's Reflection

Enterprise code is different from scripts. The patterns that work for quick prototypes - reading files directly, catching all exceptions - don't scale to production systems.

The async context manager pattern is powerful. It guarantees cleanup happens even when exceptions occur, which is essential for file handles and network connections.

Layered validation is about **separation of concerns**. The file validation layer shouldn't know about business rules, and the business layer shouldn't validate file types. This makes each layer easier to test and modify.

The dependency injection approach in FastAPI is elegant. Resources are acquired when needed and automatically cleaned up, without explicit management in every endpoint.

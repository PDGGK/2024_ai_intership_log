## Regulatory Requirements

The system checks for:

1. **Logo Verification**: Standard "blue hat" health food logo must be prominent
2. **Declaration Text**: "Health food is not medicine..." must be visible
3. **Function Claims**: Only approved health functions allowed
4. **Target Population**: Must clearly indicate suitable/unsuitable groups

## File Processing Module

```python
class FileProcessor:
    def __init__(self, config):
        self.supported_formats = {'image/jpeg', 'image/png', 'image/webp'}
        self.max_size = 10 * 1024 * 1024  # 10MB

    async def process(self, file: UploadFile) -> ProcessedFile:
        if file.content_type not in self.supported_formats:
            raise UnsupportedFormatError(f"Unsupported: {file.content_type}")

        content = await file.read()
        if len(content) > self.max_size:
            raise FileSizeExceededError(f"Size exceeds limit")

        file.file.seek(0)

        return ProcessedFile(
            filename=file.filename,
            content=content,
            content_type=file.content_type
        )
```

## Image Analysis

```python
class ImageAnalyzer:
    async def analyze_logo(self, image: ProcessedFile) -> LogoAnalysisResult:
        cache_key = f"logo_{hash(image.content)}"

        if cached := await self.cache.get(cache_key):
            return cached

        prompt = self._build_logo_analysis_prompt()
        result = await self.vl_client.analyze(image=image, prompt=prompt)

        analysis = self._parse_logo_analysis(result)
        await self.cache.set(cache_key, analysis)

        return analysis
```

## Declaration Matching

```python
class DeclarationMatcher:
    def match_declaration(self, text_blocks: List[TextBlock]) -> MatchResult:
        # Normalize text
        normalized = [self._normalize(block.text) for block in text_blocks]

        # Calculate similarity to required declaration
        similarities = [
            self._calculate_similarity(text, self.required_declaration)
            for text in normalized
        ]

        # Evaluate prominence (size, position)
        prominences = [block.prominence for block in text_blocks]

        # Combine similarity and prominence
        scores = [
            self._calculate_score(sim, prom)
            for sim, prom in zip(similarities, prominences)
        ]

        best = max(zip(text_blocks, scores), key=lambda x: x[1], default=(None, 0))
        return self._evaluate_match(best)
```

## Today's Reflection

This project taught me that **regulatory compliance systems need extraordinary precision**. Unlike recommendation systems where 90% accuracy is acceptable, compliance requires near-certainty.

Key learnings:
1. **Multiple validation layers** - never trust single-model output
2. **Caching is essential** - same ad might be reviewed multiple times
3. **Audit trails matter** - every decision needs justification
4. **Edge cases dominate** - the 10% of unusual ads take 90% of effort

The VL + LLM combination works well. VL handles perception (what's in the image), LLM handles reasoning (is it compliant). Separating these concerns allows independent optimization.

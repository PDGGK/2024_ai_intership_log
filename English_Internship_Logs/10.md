# Python Virtual Environment and FastAPI Deployment on Mac

> **Date**: 2024-11-26
> **Topic**: Virtual environment configuration, SSL issues, and FastAPI service deployment

---

## Background

Today I worked on setting up a Python development environment on Mac and deploying a FastAPI-based OCR service. The Mac environment introduced some platform-specific challenges.

---

## Virtual Environment Issues

**Problem**: Package installation paths were incorrect, SSL verification failures, and missing system dependencies.

**Solutions**:

```bash
# Virtual environment rebuild
deactivate
rm -rf .venv
python3 -m venv .venv
source .venv/bin/activate

# SSL issue workaround
pip install -r requirements_mac.txt \
  --trusted-host pypi.org \
  --trusted-host files.pythonhosted.org

# System dependency (for PDF processing)
brew install poppler
```

Mac's package management has quirks compared to Linux. Installation paths and certificate handling require extra attention.

---

## FastAPI Service Deployment

The OCR service was configured with:
- Endpoint: `http://0.0.0.0:9001`
- Swagger documentation at `/docs`
- File upload and processing APIs

FastAPI's core stack:
- **Starlette**: ASGI framework for async handling
- **Pydantic**: Data validation with type hints
- **Uvicorn**: ASGI server

This stack provides automatic API documentation, type safety, and high-performance async processing.

## Virtual Environment Evolution

The Python environment management landscape has evolved:

```plaintext
Environment Tools:  virtualenv → venv → poetry/pipenv
Package Management: pip → conda → poetry
Dependency Files:   requirements.txt → pyproject.toml
```

Modern tools like Poetry provide better dependency resolution and lock files, but venv + pip remains the most portable approach.

## Today's Reflection

Today reinforced that **environment setup is never trivial**. What works on one machine often breaks on another due to SSL certificates, missing system libraries, or path differences.

The SSL issues were particularly frustrating. On corporate networks or Macs with specific security configurations, the default certificate chain doesn't work. The `--trusted-host` flag is a workaround, but understanding why it's needed (intercepting proxies, outdated CA bundles) helps diagnose similar issues.

FastAPI impressed me with its developer experience. The automatic Swagger documentation and type-checking catch errors early. Coming from Flask, the async-first design feels more natural for I/O-bound services.

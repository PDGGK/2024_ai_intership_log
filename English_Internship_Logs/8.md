## Virtual Environment Basics

```bash
# Create virtual environment
python3 -m venv .venv

# Activate environment
source .venv/bin/activate

# Install dependencies
pip install -r requirements.txt
```

Virtual environments work by modifying the Python path:

```python
# Core logic of activation script
import os

base = os.path.dirname(os.path.dirname(os.path.abspath(__file__)))
os.environ["VIRTUAL_ENV"] = base

bin_dir = os.path.join(base, "bin")
os.environ["PATH"] = bin_dir + os.pathsep + os.environ["PATH"]
```

## Dependency Version Strategies

```txt
# requirements.txt best practices
package_name==version  # Fixed version
package_name>=version  # Minimum version
package_name~=version  # Compatible version
```

## SSL Certificate Issues

```bash
# Using mirror sources
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

# Trust configuration
--trusted-host pypi.tuna.tsinghua.edu.cn
```

## Cross-Platform Dependencies

```python
# Conditional dependency in setup.py
requirements = [
    'base_package',
    'pywin32==308; platform_system=="Windows"'
]
```

This ensures Windows-specific packages are only installed on Windows.

## VSCode Integration

The Python extension automatically detects virtual environments, but sometimes shows duplicates. Solution:
- Clean up redundant environments
- Use the Command Palette to explicitly select the interpreter
- Configure `python.defaultInterpreterPath` in settings

## Today's Reflection

Today I gained a deeper understanding of how virtual environments actually work. They're not magic - they simply manipulate PATH and PYTHONPATH to create isolation.

The key insight is that **virtual environments are critical infrastructure, not just convenience tools**. Without proper environment isolation, you'll eventually hit version conflicts that are nearly impossible to debug.

I also learned the importance of standardized environment configuration. When everyone on a team follows the same process, collaboration becomes much smoother. A simple README with setup instructions saves hours of debugging.

SSL issues were frustrating but educational. In corporate environments with proxies and certificate interception, the default trust chain often breaks. Knowing how to configure trusted hosts and mirror sources is essential.

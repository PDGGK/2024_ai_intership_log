## Module Import Issues

**Problem**: ModuleNotFoundError when importing from project packages.

```python
from vl.utils import check_file_size  # ModuleNotFoundError
```

**Root cause**: PYTHONPATH not set correctly.

**Solution**: Configure launch.json with proper PYTHONPATH:

```json
{
    "version": "0.2.0",
    "configurations": [
        {
            "name": "Python: FastAPI",
            "type": "python",
            "request": "launch",
            "module": "uvicorn",
            "args": ["startup:app", "--reload"],
            "cwd": "${workspaceFolder}",
            "env": {
                "PYTHONPATH": "${workspaceFolder}"
            }
        }
    ]
}
```

## Python Package Structure

A proper package structure avoids import issues:

```plaintext
my_project/
├── app/
│   ├── __init__.py
│   ├── api/
│   │   ├── __init__.py
│   │   └── endpoints.py
│   ├── core/
│   │   ├── __init__.py
│   │   └── config.py
│   └── services/
│       ├── __init__.py
│       └── ocr_service.py
├── startup.py
└── requirements.txt
```

Key points:
- Every directory needs `__init__.py`
- Use absolute imports from the project root
- Set PYTHONPATH to the project root

## VSCode Debugging Tips

**Setting breakpoints effectively**:
- Set breakpoints on function entry points
- Use conditional breakpoints for specific values
- Avoid breakpoints in hot loops

**Debug console commands**:

## OCR Result Processing

The OCR service returns a pages array. Extracting text:

```python
text_content = "\n".join(
    [page["content"] for page in doc_result["pages"]
     if page["status"] == "success"]
).strip()
```

**Optimization discovered**: Removing the `vl_prompt` parameter improved recognition results. The default configuration was better than my custom prompt.

## Today's Reflection

Module import errors are frustrating because the error message doesn't clearly indicate the solution. "ModuleNotFoundError" could mean:
- The module doesn't exist
- PYTHONPATH is wrong
- Missing `__init__.py`
- Wrong import syntax

The debugging taught me to check **PYTHONPATH first**. In VSCode, setting it in launch.json is essential for consistent behavior across runs.

The OCR optimization was counterintuitive. I assumed custom prompts would help, but the default configuration was better. This reinforced the principle: **start with defaults, customize only when needed**.

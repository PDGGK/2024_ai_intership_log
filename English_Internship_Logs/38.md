## API Wrapper

```python
class BaiduMapAPI:
    def __init__(self, ak):
        self.ak = ak
        self.base_url = "https://api.map.baidu.com"

    def search_place(self, query, region="Beijing"):
        url = f"{self.base_url}/place/v2/search"
        params = {
            "query": query,
            "region": region,
            "output": "json",
            "ak": self.ak,
            "tag": "residential",
            "scope": 2  # Detailed info
        }

        try:
            response = requests.get(url, params=params)
            data = response.json()
            if data.get("status") == 0:
                return data.get("results", [])
            return []
        except Exception as e:
            print(f"Error: {e}")
            return []
```

## Year Extraction

```python
def extract_year(detail_info):
    keywords = ["construction year", "completion", "built"]
    info = str(detail_info).lower()

    for keyword in keywords:
        if keyword in info:
            years = re.findall(r'19\d{2}|20\d{2}', info)
            if years:
                return int(years[0])
    return None
```

## Analysis Function

```python
def analyze_communities(filename, ak):
    api = BaiduMapAPI(ak)
    results = []

    with open(filename, 'r', encoding='utf-8') as f:
        communities = [line.strip() for line in f if line.strip()]

    for community in communities:
        places = api.search_place(community)

        if places:
            place = places[0]
            year = extract_year(place.get("detail_info", {}))

            result = {
                "name": community,
                "year": year,
                "is_old": "Yes" if year and year < 2010 else "Unknown",
                "address": place.get("address", ""),
                "lat": place.get("location", {}).get("lat"),
                "lng": place.get("location", {}).get("lng")
            }
        else:
            result = {"name": community, "is_old": "Unknown"}

        results.append(result)
        time.sleep(0.5)  # Rate limiting

    return results
```

## Statistics Output

```python
def print_statistics(results):
    total = len(results)
    old = sum(1 for r in results if r["is_old"] == "Yes")
    new = sum(1 for r in results if r["is_old"] == "No")
    unknown = sum(1 for r in results if r["is_old"] == "Unknown")

    print(f"Total: {total}")
    print(f"Old (pre-2010): {old}")
    print(f"New: {new}")
    print(f"Unknown: {unknown}")

    if total - unknown > 0:
        ratio = old / (total - unknown) * 100
        print(f"Old community ratio: {ratio:.1f}%")
```

## Today's Reflection

API rate limiting was critical - Baidu's API has strict limits. Adding `time.sleep(0.5)` between requests prevented bans.

The year extraction was tricky because different data sources format dates differently. Using regex to find 4-digit years starting with 19 or 20 worked well enough.

Key insight: **API data is inconsistent**. Many communities had no year data, so the "Unknown" category was essential. Reporting ratios both with and without unknowns gives a clearer picture.

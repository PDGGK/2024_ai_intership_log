## Community Name Extraction

Addresses in China often contain community names with specific keywords:

```python
def extract_community_name(self, address: str) -> str:
    community_keywords = ['garden', 'plaza', 'home', 'court', 'village', 'apartment']

    # 1. Match complete community names
    for keyword in community_keywords:
        pattern = f'([^0-9road street]{1,20}?{keyword})'
        match = re.search(pattern, address)
        if match:
            community = match.group(1)
            community = re.sub(r'^\d+no\.', '', community)
            return community.strip()

    # 2. Check for village names
    village_match = re.search(r'([^\d]+village)[^\d]*$', address)
    if village_match:
        return village_match.group(1)

    # 3. Extract road name as fallback
    road_match = re.search(r'([^province city\d]+?[road street])', address)
    if road_match:
        return road_match.group(1)

    return address
```

## Web Scraping for Building Years

```python
class LianjiaAnalyzer:
    def __init__(self):
        self.headers = {
            'User-Agent': 'Mozilla/5.0 (iPhone; CPU iPhone OS 13_2_3)',
            'Accept': 'text/html,application/xhtml+xml'
        }
        self.old_year_threshold = 2010

    def get_community_info(self, community_name: str) -> Dict:
        try:
            search_url = f"https://m.ke.com/city/xiaoqu/rs{quote(community_name)}/"
            response = requests.get(search_url, headers=self.headers, timeout=10)

            # Find community detail link
            detail_pattern = r'href="(/city/xiaoqu/\d+/)"'
            matches = re.findall(detail_pattern, response.text)

            if matches:
                detail_url = f"https://m.ke.com{matches[0]}"
                detail = requests.get(detail_url, headers=self.headers)

                # Extract year
                year_pattern = r'Construction Year.*?(\d{4})'
                year_match = re.search(year_pattern, detail.text)

                if year_match:
                    return {"year": int(year_match.group(1))}

            return {}

        except Exception as e:
            print(f"Error: {e}")
            return {}
```

## Data Processing Pipeline

```python
def analyze_communities(filename: str, limit: int = 10):
    analyzer = LianjiaAnalyzer()
    results = []

    with open(filename, 'r', encoding='utf-8') as f:
        addresses = [line.strip() for line in f if line.strip()][:limit]

    for address in addresses:
        # Extract community name
        community = analyzer.extract_community_name(address)

        # Get building year
        info = analyzer.get_community_info(community)

        result = {
            "address": address,
            "community": community,
            "year": info.get("year"),
            "is_old": info.get("year", 9999) < 2010
        }
        results.append(result)

        time.sleep(2)  # Rate limiting

    return pd.DataFrame(results)
```

## Best Practices

1. **Rate Limiting**: 2 second delay between requests
2. **Mobile Headers**: Real estate sites often have better mobile APIs
3. **Error Handling**: Save partial results on failure
4. **Data Validation**: Check year ranges make sense (1950-2024)

## Today's Reflection

Address parsing in Chinese is complex because there's no standard format. The multi-level extraction strategy (keywords → village → road) handles most cases, but edge cases remain.

Web scraping is fragile - any site redesign breaks the parser. For production, consider:
- Official APIs if available
- Multiple data sources for redundancy
- Regular validation against known data

The 2010 threshold for "old" was somewhat arbitrary. In practice, this should be configurable based on the use case.

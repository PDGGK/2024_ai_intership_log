## Background

Today I explored using Vision-Language (VL) models for image comparison, moving away from traditional computer vision approaches like feature point matching.

---

## Traditional vs VL Model Approaches

**Traditional Methods**:
- SIFT feature matching
- Pixel-level comparison
- OpenCV toolchain

**VL Model Methods**:
- Semantic understanding
- Natural language descriptions
- High-level feature comparison

VL models excel at describing *what's different* in human-understandable terms, not just detecting numerical differences.

## Handling LLM JSON Output

LLMs often produce non-standard JSON. A sanitization function helps:

```python
def sanitize_json_string(text: str) -> str:
    # Extract JSON from markdown code blocks
    json_match = re.search(r'```(?:json)?(.*?)```', text, re.DOTALL)
    if json_match:
        text = json_match.group(1).strip()

    # Clean up formatting
    text = text.replace('\n', ' ')
    text = re.sub(r'(\w+):', r'"\1":', text)  # Quote keys

    return text
```

## Today's Reflection

The switch to VL models was eye-opening. Traditional image comparison tells you "these images differ by 15% in pixel values." VL models tell you "the first image uses a blue color scheme, while the second uses red; both have the same layout with centered content."

The trade-off is clear: VL models are slower and more expensive, but provide richer, more actionable insights. For compliance checking where you need to explain *why* something is different, VL models are worth it.

The JSON parsing issues were frustrating but solvable. LLMs are inconsistent with output formatting, so robust sanitization is essential.

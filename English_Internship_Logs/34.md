## Memory Management Strategy

```python
class MemoryManager:
    def __init__(self, threshold_mb=1000):
        self.threshold_mb = threshold_mb

    def check_memory(self):
        torch.cuda.synchronize()
        allocated = torch.cuda.memory_allocated() / 1024**2
        cached = torch.cuda.memory_reserved() / 1024**2
        return allocated, cached

    def optimize_memory(self, model, input_size):
        allocated, cached = self.check_memory()
        if allocated > self.threshold_mb:
            torch.cuda.empty_cache()

            # Enable gradient checkpointing
            if hasattr(model, 'gradient_checkpointing_enable'):
                model.gradient_checkpointing_enable()

            # Calculate optimal batch size
            ratio = self.threshold_mb / allocated
            return max(1, int(current_batch_size * ratio))
        return None
```

## Prefetch Loader with CUDA Streams

```python
class PrefetchLoader:
    def __init__(self, loader):
        self.loader = loader
        self.stream = torch.cuda.Stream()

    def __iter__(self):
        loader_it = iter(self.loader)
        self.preload(loader_it)
        batch = self.next_batch

        while batch is not None:
            yield batch
            batch = self.preload(loader_it)

    def preload(self, it):
        try:
            self.next_batch = next(it)
        except StopIteration:
            self.next_batch = None
            return

        with torch.cuda.stream(self.stream):
            if isinstance(self.next_batch, torch.Tensor):
                self.next_batch = self.next_batch.cuda(non_blocking=True)
```

The CUDA stream allows data transfer to happen concurrently with computation.

## Performance Monitoring

```python
class PerformanceMonitor:
    def __init__(self):
        self.metrics = defaultdict(list)

    @contextmanager
    def measure_time(self, operation: str):
        start = time.time()
        try:
            yield
        finally:
            duration = time.time() - start
            self.metrics[operation].append(duration)

    def get_summary(self):
        summary = {}
        for op, times in self.metrics.items():
            summary[op] = {
                'mean': np.mean(times),
                'max': np.max(times),
                'min': np.min(times),
                'std': np.std(times)
            }
        return summary
```

## Today's Reflection

Performance optimization is a system-wide concern. GPU memory is often the bottleneck, but CPU, disk I/O, and data loading can all limit throughput.

The prefetch loader was a significant improvement. By loading the next batch while processing the current one, we hide data loading latency. The key is using CUDA streams correctly - `non_blocking=True` is essential.

Gradient checkpointing trades compute for memory. It recomputes activations during backward pass instead of storing them. For memory-constrained scenarios, it's valuable, but it slows training by ~20-30%.

The monitoring system helps identify bottlenecks. Without measurement, optimization is guesswork.
